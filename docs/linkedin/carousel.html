The problem

Why agents write slop

1

They plan before they understand

An eager plan built on assumptions nobody questioned.

2

They build in horizontal layers

Phase 1: database. Phase 2: API. Phase 3: UI. No feedback until the end.

3

They write tests after the code

Tests shaped to fit whatever the code already does.

4

They work in the dumb zone

Past ~100k tokens, reasoning quality drops, whatever the window size.

5 rules it enforces

Old books.
New agents.

01

Grill before you plan

Shared understanding beats a pretty plan.

02

Tracer bullets, not layers

Every task cuts through DB, API and UI and ends in something clickable.

03

Red before green

No code until a failing test proves what "done" means.

04

Clear, don't compact

Small tasks, fresh sessions, stay in the smart zone.

05

Deep modules

You own the interfaces. Agents own the internals.
