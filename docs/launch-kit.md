## X / Bluesky thread

1. AI agents don't need a bigger framework. They need the engineering fundamentals we already have, written down so they follow them every time.

   I packaged mine as a Claude Code skill 🧵
   github.com/khakpour27/madmattskills

2. Step 1: grill. Before any plan, the agent interviews you one question at a time, each with a recommended answer. It catches the questions nobody asked, like "do we backfill existing data?"

3. Step 2: the PRD, a destination doc. User stories, which modules change, how it's tested, and what's explicitly out of scope.

4. Step 3: tracer bullets. Every issue is a thin vertical slice through DB, service, API and UI that ends in something clickable. No "Phase 1: database".

5. Step 4: the night shift. A loop runs one issue per fresh session: failing test, minimal code, refactor, types and lint green, commit, stop.

6. Step 5: review in a fresh context with your standards pushed in, then human QA. QA findings become new issues.

7. Plain markdown and bash. Fork it and make it yours.

   `/plugin marketplace add khakpour27/madmattskills`
